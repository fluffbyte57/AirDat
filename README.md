This is an iOS-targeted app (possibly may work on iPadOS but that hasn't been tested) that I made / am actively working on that allows pilots to get a rough idea of runways, difference between magnetic and true headings in their area, get weather data (or the METAR) for their local airport and airport location

Features I'm working on: 
- [x] simulate RWY headings
- [ ] Grab METAR via search (hopefully thru an API)
- [ ] METAR decoding function via old system from my METAR-Decoder project
- [ ] Find Airport location
